# Employee & Passport Management (Hibernate)

## Overview
A Hibernate ORM project demonstrating a One-to-One relationship between Employee and Passport using MySQL.

## Technologies
- Java 21
- Hibernate ORM
- MySQL
- Maven

## Features
- Create Employee
- Assign Passport
- Retrieve Employee with Passport
- Delete Employee
- One-to-One Mapping
- Cascade Delete
- Eager Loading
- Duplicate Passport Number Validation

## Test Cases
- Employee without Passport
- Duplicate Passport Number
- Cascade Delete
- Eager Loading Verification

## Project Structure
- Entity Layer
- DAO Layer
- Hibernate Utility
- Console-Based Main Application
